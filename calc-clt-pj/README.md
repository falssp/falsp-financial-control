# Calculadora CLT vs PJ

Calculadora financeira interativa para comparação de regimes de contratação.

## Acesso

🔗 [https://falssp.github.io/falsp-financial-control/calc-clt-pj/](https://falssp.github.io/falsp-financial-control/calc-clt-pj/)

## O que calcula

- **CLT**: bruto → líquido (INSS e IRRF progressivos 2026), 13º, férias + ⅓, FGTS, PLR, VA/VR, home office, plano de saúde
- **PJ**: todos os regimes tributários (MEI, Simples Anexo III, Simples Anexo V, Lucro Presumido, Autônomo/RPA, alíquota customizada), despesas mensais, INSS próprio, provisão FGTS, férias por oportunidade
- **Break-even**: nota fiscal mínima para igualar o pacote CLT
